# easyexcel-rust 全量迁移路线图

> 版本：v1.0（2026-07-28）｜基线：Alibaba EasyExcel **4.0.3**
> 仓库：easy-4-rust/easyexcel-rust @ dev ｜本文档随代码同步维护，每阶段完成时更新

## 一、总目标

以 Alibaba EasyExcel 4.0.3 为蓝本，实现**功能语义完全对齐**的
easyexcel-rust crate，覆盖读取、写入、模板填充、转换器、处理器和加密的
XLSX/XLS/CSV 全链路。

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：Java 反射 → trait 对象 + 过程宏；
   Java 泛型擦除 → Rust 编译期泛型；Java 异常 → Result 错误处理
2. **每个 .rs 文件只对应一个 Java 对象**：对齐 vernal-expression 的一文件一对象规范
3. **所有公开类型必须有文档注释**：结构体、枚举、trait、方法
4. **模块路径 snake_case**，类型 PascalCase，方法 snake_case
5. **与 Java 输出兼容**：通过 Golden 测试验证 XLSX/XLS/CSV 产物一致性
6. **不实现运行时反射**：Rust 编译期类型系统替代 Java 运行时反射

## 四、工程规范

### 命名规则

| 项目 | 规范 |
|------|------|
| 目录/文件名 | snake_case（`excel_reader.rs`、`default_converter_loader.rs`）|
| 类型名 | PascalCase（`ExcelReader`、`DefaultConverterLoader`）|
| 方法名 | snake_case（`do_read`、`convert_to_excel_data`）|
| 参数名 | 与 Java 一致（`read_sheet`、`write_workbook`）|

### 文件结构规范

```rust
//! 对应 Java 类：com.alibaba.excel.ExcelReader
//!
//! Excel 读取器入口，基于事件驱动模式读取 Excel 文件。
//! 支持 XLSX、XLS、CSV 三种格式。

/// Excel 读取器。
///
/// 对应 Java `ExcelReader`，泛型参数：
/// - `T: ExcelRow` — 行数据类型
/// - `L: ReadListener<T>` — 读取监听器
pub struct ExcelReader<T, L> {
    analyser: ExcelAnalyserImpl,
    listener: L,
    marker: PhantomData<T>,
}
```

### 测试规范

- 每个核心类型至少 1 个单元测试
- Builder 覆盖所有方法变体
- Golden 测试覆盖所有 Java 测试场景
- 1:1 对等测试验证行为一致性
