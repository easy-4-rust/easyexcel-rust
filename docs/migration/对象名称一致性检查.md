## 四、命名约定审计

| Java 约定 | Rust 约定 | 示例 |
|----------|----------|------|
| camelCase | snake_case | `doRead` → `do_read` |
| `Abstract*` 前缀 | `Abstract*` 前缀 | `AbstractCellStyleStrategy` |
| `get*/set*` 前缀 | 无前缀 | `getSheetNo()` → `sheet_no()` |
| `*Impl` 后缀 | `*Impl` 后缀 | `ExcelAnalyserImpl` |
| static factory | module fn | `EasyExcel.write()` → `EasyExcel::write()` |
| interface | trait | `ReadListener` → `ReadListener<T>` |
| class with state | struct | `ExcelReader` → `ExcelReader<T, L>` |
| overload（同名不同签名） | 独立方法名 | `write(Collection)` / `write(Supplier)` → `write()` / `write_supplier()` |
| `@Deprecated` | `#[deprecated]` | `read()` → `#[deprecated] read()` |
