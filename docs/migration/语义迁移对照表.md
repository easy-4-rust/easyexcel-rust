# easyexcel (Java) → easyexcel-rust 功能语义迁移对照表

基线：Alibaba EasyExcel **4.0.3**。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的反射、泛型擦除、异常分别映射为：过程宏、编译期泛型、Result 错误处理。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移 / 🚫 不迁移（Rust 原生替代）
